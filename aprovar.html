Conectar ao GitHub

Para aprovar posts por aqui, esta tela precisa de uma chave de acesso ao seu repositório. Você faz isso uma vez só, e a chave fica salva só neste aparelho.

  1. Abra Criar chave no GitHub.
  2. Token name: aprovar-tiktok. Expiration: 1 ano.
  3. Repository access: Only select repositories → tiktok-carrossel.
  4. Permissions → Repository: Actions = Read and write e Contents = Read and write.
  5. Toque em Generate token, copie e cole abaixo.
