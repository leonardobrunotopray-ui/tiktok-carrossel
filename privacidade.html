Política de Privacidade

Última atualização: novembro de 2026

O Carrossel Finanças é usado apenas pelo titular de um canal do TikTok para publicar o próprio conteúdo.

Dados tratados

  • Identificador da conta (open_id) e nome de usuário, para saber em qual conta publicar.
  • Tokens de acesso fornecidos pelo TikTok, guardados de forma criptografada e usados somente para publicar e consultar o status das publicações.
  • As imagens e textos dos posts, que são do próprio titular.

Compartilhamento

Nenhum dado é vendido nem compartilhado com terceiros. Os dados só são enviados ao TikTok, pela API oficial, no momento da publicação.

Exclusão

Revogar o acesso do app nas configurações do TikTok invalida os tokens. O titular pode apagar os tokens armazenados a qualquer momento.

Contato

Pelo repositório do projeto no GitHub.
